核心设计理念

极致毛玻璃

深度借鉴原生毛玻璃设计语言，采用 backdrop-filter 实时模糊、精妙的圆角曲率、自然的动画曲线，让每一块卡片都通透如玉，光线与层次自然流动。

流畅动效

遵循 iOS 级动画缓动曲线 cubic-bezier，从出现、悬浮到消失，每一个过渡都追求 60fps 的丝滑体验，让交互充满呼吸感与生命力。

昼夜双主题

支持白天/暗色模式一键切换，智能记忆用户偏好。毛玻璃在明暗主题下均呈现最优通透质感，全天候护眼舒适，色彩对比度严格符合 WCAG 标准。

我们的故事 · 一群学生的梦想起点

🎓 学生创作团队 · Student-Led Studio

XEOM 工作室不是一家商业公司，而是一群分散在不同城市、不同区域的在校学生， 因对极致毛玻璃美学、对精致数字产品的共同热爱，跨越地域在网络上相聚，在课余时间自发组建的创作团队。

我们中有高中生、有大学生，天南海北——写代码的在一座城市、做设计的在另一座，有搞产品的、有玩动效的—— 白天各自上课，深夜通过语音、文档、代码仓库协作，在宿舍、在图书馆、在各自城市的台灯下，共同打磨一份作品。

2026 年 9 月 4 日，XEOM 在一场跨城市的线上会议中正式宣告成立。 这不是一场商业冒险，而是一群天各一方的年轻人，想把"喜欢"变成"作品"的认真尝试。

🧩 三层产品体系

我们做什么 · 模块 · 应用 · 系统

从底层组件到独立应用、再到完整系统，XEOM 以三层结构层层递进，把毛玻璃美学落实到每一个层级。

🧩
Layer 01

模块 · Modules

可复用的毛玻璃 UI 组件、动画库、系统级模块（如状态栏、通知中心、控制中心、启动器主题模块等）， 为上层应用和系统提供稳定、美观、高性能的基础组件。

  • ✓跨端毛玻璃组件库（Web / Android / iOS）
  • ✓系统级 Magisk / LSPosed 视觉模块
  • ✓iOS 越狱美化主题模块（Snowboard 等）
  • ✓动效与模糊渲染优化内核
组件库 系统模块 主题引擎
📱
Layer 02

应用 · Applications

基于自研毛玻璃模块打造的独立应用：桌面启动器、天气、笔记、音乐、设置工具等， 每一款都贯彻通透质感与极致动效，让用户真正摸到 XEOM 美学。

  • ✓XEOM Launcher · 毛玻璃桌面启动器
  • ✓毛玻璃天气 / 笔记 / 音乐等垂直应用
  • ✓主题与壁纸管理器
  • ✓跨平台设计工具 / 小组件
启动器 独立 App 工具集
⚙️
Layer 03

系统 · Systems

最高层级的野心：基于自研模块与应用，打造整套毛玻璃 ROM / 操作系统体验。 从启动、锁屏、桌面到系统应用，每一帧都通透、每一次交互都丝滑。

  • ✓XEOM OS · 毛玻璃定制 ROM（安卓侧）
  • ✓iOS 端完整系统主题包
  • ✓统一的设计系统与动效语言
  • ✓开源社区协同迭代
定制 ROM 系统主题 设计系统

模块是基石，应用是窗口，系统是终局。
三层相互支撑、共同迭代——我们用学生团队的执着，一层一层往上搭建属于 XEOM 的毛玻璃数字世界。
